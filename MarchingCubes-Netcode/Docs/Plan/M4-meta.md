# M4 — Мета-игра: профиль, лагерь, вылазка, глубины

Цель: петля «забег → награда → покупка → забег сильнее» (Vampire Survivors, Megabonk)
и карты, которые **всегда случайные**, но по **рецепту**, зависящему от яруса и глубины.

Оценка: 4–5 сессий. Зависит от M1. Может идти параллельно с M2.

---

## M4.1 Структура вылазки

```
Лагерь ─► Ярус 1 (5:00 + Ткачиха) ─► привал ─► Ярус 2 (6:00 + Кислотница) ─► привал ─► Ярус 3 (7:00 + Праматерь) ─► Победа
             │ смерть                           │ смерть                             │ смерть
             └──────────────► Итоги ◄───────────┴────────────────────────────────────┘
```

* **Ярус** — новые катакомбы со своим сидом и рецептом (M4.7). Таймер и Матка — как сейчас;
  длина стадии директора (`stageSeconds`) берётся из рецепта.
* **Переход**: смерть Матки → катакомбы озаряются (уже есть) → в зале логова открывается
  **провал** (точка с ореолом) → подошёл, E → `GameFlow.Loading` → генерация следующего яруса.
  Генерация идёт по бюджету кадров (`CatacombSettings.MillisecondsPerFrame`) — экран
  загрузки с советом и прогрессом `CatacombWorld.Progress`.
* **Привал** (экран между ярусами): лечение 30%, одна бесплатная карточка, рекламная
  «полное лечение» (M5). Рост игрока (уровень, пушки, тома) **переносится** на следующий ярус.
* **Контрольная точка**: при входе на ярус сохраняется снимок забега (класс, глубина, ярус,
  уровень, опыт, пушки с уровнями, тома, здоровье, сид). Перезагрузка страницы → «Продолжить
  вылазку с яруса N». Требование Яндекса 1.9 — прогресс не теряется при обновлении страницы.
* **Длина**: смерть новичка — 3–5 мин на ярусе 1; полная вылазка — ~20 мин. Веб-сессии
  такой длины нормальны; полной вылазке есть на что опираться (контрольные точки).

## M4.2 Профиль и сохранения

`PlayerProfile` — обычный сериализуемый класс (JsonUtility: **без словарей** — списки пар):

| группа | поля |
|---|---|
| служебное | `version`, `saveCounter` (растёт с каждым сохранением), `createdAt`, `lastSeenDay` |
| валюта | `chitin`, `chitinEarnedTotal` |
| открытия | пушки, классы, тома (для пула карточек), глубины |
| покупки | уровни мета-улучшений |
| выбор | класс, стартовая пушка, глубина |
| статистика | забегов, убито всего, по пушкам, Маток по видам, лучшая глубина, лучшие времена |
| задания | прогресс постоянных, ежедневные (день, три задания, прогресс), серия входов |
| настройки | чувствительность, инверсия, громкости, качество, язык, цифры урона, автоогонь (тач) |
| обучение | флаги показанных подсказок (M1.10) |
| реклама | счётчики для частоты (M5) |
| забег | снимок контрольной точки (M4.1) или пусто |

* **`SaveService`** с бэкендами: `LocalSaveBackend` (PlayerPrefs; на WebGL — IndexedDB,
  после записи `PlayerPrefs.Save()`), `YandexSaveBackend` (`player.setData`), `CrazySaveBackend`
  (модуль Data SDK v3). Выбор — по платформе (M5).
* **Слияние**: при загрузке читаются локальное и облачное, берётся с большим `saveCounter`;
  при равенстве — с большим `chitinEarnedTotal`. Купленное не теряется никогда.
* **Когда сохранять**: после покупки, смены выбора и настроек, на контрольной точке, в итогах.
  Не в каждом кадре и не по таймеру — у облака лимиты частоты; копить «грязный» флаг
  и сбрасывать не чаще раза в 5 с.
* **Миграции**: `version` + цепочка функций `Migrate_N_to_N+1`, тест на каждую (EditMode).

## M4.3 Лагерь (хаб)

Не отдельная сцена (M0.5): интерфейс поверх **маленьких катакомб с фиксированным сидом**
(2×2×2 чанка — генерация за доли секунды), камера медленно облетает зал с костром
и зажжёнными лампами. Атмосфера без новых ассетов.

| вкладка | что |
|---|---|
| **В бой** | большая кнопка, класс, глубина, стартовая пушка; «Продолжить вылазку», если есть снимок |
| **Арсенал** | 8 пушек: открытие за хитин или заданием, стартовая пушка, статистика пушки |
| **Улучшения** | сетка мета-улучшений (M4.4) |
| **Классы** | M4.5 |
| **Задания** | постоянные и ежедневные (M4.6) |
| **Настройки** | M4.2 |

**Новый игрок лагеря не видит**: первый запуск — сразу ярус 1 (требование CrazyGames:
в игру сразу или за один клик). Лагерь появляется после первой смерти, с подсветкой
«Улучшения — у тебя 140 хитина».

## M4.4 Хитин и мета-улучшения (PowerUps VS)

**Хитин** — с элиты (15), Маток (60/120/250 по ярусам), 1 из ~30 рядовых (1), заданий;
умножается на «Жадность» и множитель глубины. Цель экономики: **первое улучшение после
первой смерти, что-то новое каждые 1–2 забега первые 2 часа**, полное прохождение меты —
10–15 часов.

Цена уровня = `база × (1 + 0.1 × куплено_всего_уровней)` — как в VS: каждая покупка
дорожает и остальные. Кнопка «Сбросить» возвращает весь хитин (VS так же) — бесплатная
перестройка снимает страх ошибиться.

| улучшение | за уровень | уровней | база |
|---|---|---|---|
| Сила | +5% урона | 5 | 120 |
| Броня | +1 | 3 | 200 |
| Живучесть | +10% здоровья | 3 | 150 |
| Регенерация | +0.15 HP/с | 5 | 160 |
| Темп | +3% скорострельности | 3 | 180 |
| Охват | +5% площади | 2 | 200 |
| Проворство | +4% скорости | 2 | 150 |
| Магнит | +20% радиуса | 2 | 100 |
| Удача | +8% шанс редкой карточки | 3 | 220 |
| Жадность | +10% хитина | 5 | 100 |
| Чутьё | +4% опыта | 5 | 140 |
| Возрождение | +1 | 1 | 1500 |
| Перебросы | +2 | 3 | 250 |
| Пропуски | +1 | 3 | 150 |
| Изгнания | +1 | 3 | 300 |
| **Фонарь** | +15% дальности фонаря | 3 | 180 |
| **Чутьё логова** | указатель логова с начала стадии, а не с 1:30 | 1 | 400 |

Последние два — свои для этой игры: темнота катакомб — настоящее препятствие
(`CLAUDE.md`: «Весь забег идёт в темноте… могут оказаться слепыми»), и покупка света —
понятная игроку награда.

## M4.5 Классы

Класс = стартовая пушка + пассивка + небольшой сдвиг базовых статов. Открываются
заданиями (Megabonk) — каждый класс это цель на несколько забегов.

| класс | пушка | пассивка | открытие |
|---|---|---|---|
| Рейнджер | Барабан | +10% площади | с начала |
| Стрелок | Монета | монеты восполняются вдвое быстрее, +10% крита | дойти до яруса 2 |
| Штурмовик | Ядро | +2 брони, отброс ×1.25 | пережить 60 с финального роя |
| Шахтёр | Забой | +20% здоровья, пробой без отката раз в 30 с | убить 3 Матки |
| Огнеборец | Напалм | не горит, горение ×1.3 | убить 5 000 пауков огнём |
| Электрик | Дуга | +1 громоотвод | убить Праматерь |

Умения класса на отдельной кнопке — **не делать в первой версии**: на таче это шестая кнопка.

## M4.6 Задания

* **Постоянные** (40–60 на старте): по пушкам («500 убийств дробовиком»), по Маткам
  («Ткачиха до 2:30»), по стилю («ярус без урона от плевуна»), по глубинам. Награды —
  хитин, открытия пушек и классов, косметика оружия (окраска модели — дёшево и ценится).
* **Ежедневные** (3 в день, обновление по дню из профиля): короткие, на 1–2 забега
  («убей 2 элиты», «пройди ярус 1 с Гвоздомётом»). Это главный инструмент возврата (M6).
* **Серия входов**: 7 дней, хитин по нарастающей, на 7-й — открытие косметики.
* Прогресс считается из событий M0.3 (`SpiderKilled` с источником) и M1 (урон, смерть)
  одним `QuestTracker`, не разбросанными счётчиками.

## M4.7 Рецепт уровня: «всегда случайно, но по кривой»

Карта генерируется заново на каждом ярусе (сид случайный), а **рецепт** выбирается по
ярусу и глубине. Рецепт — набор переопределений `CatacombSettings`, применяемый к **копии
ассета** (`Instantiate(settings)`): правка самого ассета в рантайме в редакторе осядет
в файле (грабли №8 в рантайм-виде).

| ручка | ярус 1 | ярус 2 | ярус 3 | зачем |
|---|---|---|---|---|
| `worldSizeInChunks` | 4×3×4 | 5×3×5 | 5×4×5 (6×4×6 на глубине ≥ 4) | ярус 1 маленький — логово находится за пару минут |
| `levelCount` | 2 | 3 | 3–4 | этажи — главная запутанность |
| `roomsPerLevel` | 6–8 | 8–11 | 10–14 | |
| `galleryShare` | 0.45 | 0.35 | 0.3 | галереи прощают новичка: длинная линия = безопасная стрельба |
| `pinchChance` | 0.2 | 0.3 | 0.4 | щели с паутиной — стресс отхода |
| `pathChaos` | 0.4 | 0.6 | 0.75 | |
| лампы / жилы | ×1.2 | ×1.0 | ×0.7 | глубже — темнее |
| паутина | ×0.7 | ×1.0 | ×1.3 | |
| `stageSeconds` | 300 | 360 | 420 | |

**Цена размера** (WebGL без воркеров — всё на главном потоке): сетка пауков сейчас
409 600 клеток и 13 МБ на 5×4×5 (`CLAUDE.md`, «Цена»); 6×4×6 — 590 000 клеток, ~19 МБ
и в 1.4 раза дольше постройки. Каждую ячейку таблицы проверить замером **генерации
и постройки сетки в сборке WebGL** (M5): бюджет — до 3 с на ноутбуке, до 6 с на телефоне
среднего класса. Если не влезает — уменьшать рецепт, а не терпеть.

**Правила уровня не трогаются** рецептом: тупиков 0, связность 100%, зал логова (M3.4) —
проверка `CatacombBatchCheck` на каждом рецепте, по три сида минимум (грабли №13).

## M4.8 Кривая сложности

Сложность складывается из трёх множителей, и **ни один не зависит от мета-покупок**:

```
живучесть особи = вид × HitPoints × время(t) × ярус × глубина
укус           = BiteDamage × урон(t) × ярус × глубина
население      = basePopulation × давление(t) × ярус_насел × глубина_насел × качество (M5)
```

* **Время внутри яруса** — нынешняя `RunCurve` и директор. Рост живучести `healthGrowth`
  поднять с 0.5 до ~1.5: в `CLAUDE.md` прямо сказано, что он скромный, потому что роста
  игрока нет, и **его первым поднимать, когда появятся улучшения**. Конкретное число —
  из `ProgressionSim` (M6).
* **Ярус**: живучесть ×1 / ×2 / ×3.5, укус ×1 / ×1.4 / ×1.9, население ×1 / ×1.15 / ×1.3.
* **Глубина** (уровни сложности, открываются победой над Праматерью на предыдущей):

| глубина | живучесть | укус | население | хитин | что добавляется |
|---|---|---|---|---|---|
| 1 | ×1 | ×1 | ×1 | ×1 | — |
| 2 | ×1.6 | ×1.3 | ×1.1 | ×1.5 | особые с яруса 1 |
| 3 | ×2.5 | ×1.6 | ×1.2 | ×2.2 | милосердие выключено; элита с двумя аффиксами |
| 4 | ×3.8 | ×2 | ×1.3 | ×3 | карты 6×4×6; «тьма»: лампы ×0.5 |
| 5 | ×5.5 | ×2.5 | ×1.4 | ×4 | финальный рой на 60 с раньше |
| 6+ «Бездна N» | ×5.5·1.35^(N−5) | ×2.5·1.2^(N−5) | ×1.4 | ×4 + 0.5·(N−5) | бесконечно; **лидерборд по глубине** (M5) |

* **Мягкий старт**: первые три забега профиля — население ×0.8, укус ×0.75, без особых.
  Невидимо. После третьего — обычная кривая. Это не подстройка под игрока, а обучение:
  новичок не знает рывка, а смерть на первой минуте первого забега — уход навсегда.
* **Рекомендованная глубина** в лагере — по доле прошлых забегов на ней, дошедших до яруса 3.

## Критерии готовности M4

| проверка | ожидание |
|---|---|
| EditMode-тесты | сложение статов (класс + мета + тома), цены с ростом, сброс улучшений, слияние сохранений (локальное/облачное, равные счётчики), миграции версий, генерация ежедневных заданий по дню |
| `RecipeCheck` (новый) | для каждой пары (ярус, глубина ≤ 4) на трёх сидах: связность 100%, тупиков 0, зал логова есть, время генерации и постройки сетки, память сетки |
| `SaveCheck` | профиль → JSON → профиль без потерь; снимок забега восстанавливает забег (уровень, пушки, тома, ярус) |
| ручной проход | первый запуск сразу в забег; после смерти — лагерь с подсказкой; покупка → эффект в следующем забеге |
| `CLAUDE.md` | разделы «Вылазка и ярусы», «Профиль и сохранения», «Рецепт уровня», «Кривая сложности»; закрыть «Одна стадия на уровень» |
