# M2 — Оружие: каркас и восемь пушек

Цель: восемь пушек, **разных по впечатлению**, а не по числам. Ориентир по ощущению —
Ultrakill (у каждой пушки свой ресурс, альтернативный огонь, который меняет способ игры,
и комбинации между пушками), по ближнему бою — Vermintide 2 (рассечение толпы, вес удара,
временное здоровье). Жанровое ограничение проекта остаётся главным: **отход по коридору
с длинными простреливаемыми галереями** (`CLAUDE.md`, «Жанровая цель»).

Оценка: каркас + API урона — 2 сессии; по 1 сессии на пушку (кроме переезда гранатомёта).
Зависит от M0, M1 (статы, события убийств, временное здоровье).

## M2.1 Каркас

```
Catacombs/Weapons/
  Core/        WeaponDef (ScriptableObject), Weapon (абстрактный, не MonoBehaviour),
               PlayerArsenal (MonoBehaviour), CombatContext, WeaponStats, HitFeedback
  Projectiles/ ProjectileSystem — общий симулятор снарядов (гранаты, гвозди, ядро, монеты, плевки врагов)
  Fx/          WeaponFx — пулы вспышек, трассеров, лучей, молний; расширение CaveExplosions
  Guns/        GrenadeLauncherWeapon, RevolverWeapon, ShotgunWeapon, NailgunWeapon,
               RailWeapon, FlamerWeapon, TeslaWeapon, PickHammerWeapon
  Views/       по модели на пушку из MeshKit (как LauncherModel)
```

* **`WeaponDef`** (ассет на пушку в `Assets/Resources/Data/Weapons/`): id, ключи имени
  и описания, иконка, базовые `WeaponStats` (урон, темп, магазин, перезарядка, разброс,
  дальность, площадь, пробитие, снаряды, отброс, сила статуса), **пять уровней** — дельты
  статов и ключ текста карточки, уровень открытия альт-огня (3), эволюция
  (`{парный том, мин. уровень тома 3, ключ имени эволюции}`), цена и условие открытия (M4),
  набор звуков. Значения проставляет «Починить свет» явно, как пресеты материалов (грабли №8).
* **`Weapon`** — обычный C#-класс: `OnEquip(ctx)`, `OnHolster()`, `Tick(in PlayerCommands, dt)`,
  `TickView(dt)`, `HudState` (патроны / нагрев / заряд / откат альта), `Level`, `Evolved`.
  Не `MonoBehaviour`: три пушки в руках — три объекта логики, а не три компонента с `Update`,
  порядок которых не гарантирован.
* **`PlayerArsenal`** — компонент на теле игрока: три слота, активный, смена (1/2/3, колесо,
  кнопка на таче), 0.15 с на смену (почти мгновенно, как в Ultrakill — переключение
  посреди очереди должно быть приёмом, а не наказанием). Убранная пушка **дотикивает**
  перезарядку и остывание — иначе смена пушки на время перезарядки не работает как приём.
* **`CaveGrenadeLauncher` переезжает** в `GrenadeLauncherWeapon` без изменения поведения.
  `Detonate(point, normal)` остаётся публичным (стенд, клавиша B, прогоны) — фасадом на арсенале.
  Модель, эффекты, воронки и гарь — как есть; `CaveExplosions` и `CaveBlastMarks` становятся
  общими для всех пушек.
* **`CombatContext`**: толпа, Матка, одиночки (M3), мир, эффекты, следы взрывов, тело игрока,
  `PlayerStats`, `HitFeedback`. Пушка ничего не ищет по сцене сама (грабли №61:
  `FindAnyObjectByType` не видит `DontSave`).

## M2.2 API урона толпе

Сейчас у толпы один вид поражения — сфера (`DamageAt`) и взрыватель (`TouchesSpider`).
Нужны формы, которые дают разное ощущение. Все — в `SpiderCrowd` (лучше отдельным
`partial`-файлом `SpiderCrowd.Combat.cs`, файл и так 2600 строк), все пишут `KillRecord`
с источником (M0.3) и возвращают `HitReport { hits, killed, gibbed, firstHitPoint }`.

| вызов | форма | кто пользуется |
|---|---|---|
| `HitSphere` | сфера со спадом урона и отбросом (обобщение `DamageAt`) | взрывы, удар молота, выдох огнемёта |
| `HitRay` | капсула вдоль луча, **упорядоченно по дальности**, до N целей, спад на каждую следующую | револьвер, рельса, гвозди |
| `HitCone` | конус с дальностью и спадом по расстоянию | дробовик, огнемёт, дуга молота |
| `FindNearest` | до K ближайших живых в сфере/конусе с фильтром (элита, не в огне…) | молния, монета, помощь прицеливания (M5) |
| `ApplyStatus` | статус в сфере/конусе/по номеру особи | горение, замедление, оглушение, ток |
| `Stagger` | толчок вдоль поверхности + оглушение на время | дробовик, молот, выдох |

**Луч не бьёт сквозь породу.** Длина `HitRay` обрезается лучом физики по чанкам (он
начинается в пустоте — это допустимо, грабли №1 про лучи, начатые в породе), маска
слоёв **без капсулы игрока** (грабли №64).

**Сфера и конус тоже не должны бить сквозь стенку** — сейчас `DamageAt` бьёт: граната
в одном ходе убивает пауков в соседнем через тонкую перегородку. Лечится не лучами
на каждую особь, а **тем же полем потока**: `SpiderFlowField.Reach` от клетки удара
на `ceil(радиус / размер клетки) + 1` шагов даёт множество клеток, связанных ходами, —
бьются только особи в них. Это та же заливка, которой выводок Матки не вылезает из-за стены.
Цена — заливка на каждый взрыв: принести замер; если дорого на гвоздях и огне, включать
только для форм с радиусом > 2.

**Статусы — поля `SpiderState`:** `Burn` (с), `BurnDps`, `Slow` (с), `SlowScale`,
`Stun` (с), `Shock` (с). Тикает их отдельный параллельный `SpiderStatusJob` (урон
от горения пишет метки убитых с источником пушки, поджёгшей особь). `SpiderMoveJob`
читает `Slow` (скорость) и `Stun` (стоит на месте, анимация бега на нуле). Распространение
огня — раз в 0.25 с на главном потоке: до 32 горящих, запрос соседей по пространственной
сетке. **`SpiderState` растёт** — в инстанс отрисовки состояние не едет, но каждый джоб
толпы читает и пишет структуру целиком, и на 1200 особях лишние байты — это проход памяти
в каждом джобе. Принести шаг поведения до и после (`CatacombCrowdCheck`); если вырос
заметно — статусы вынести в отдельный параллельный массив, который читают только те, кому нужно.

**Тип урона влияет на разлёт:** взрыв рвёт на куски (как сейчас, `gibShare`), пуля —
кувырок трупа, огонь — труп чернеет (оттенок умножением, грабли №22), ток — короткая
судорога. Код разлёта уже есть; нужна лишь ветка по `DamageKind`.

## M2.3 Ощущение: что делает пушку «как в Ultrakill»

У каждой пушки обязательный набор обратной связи (`HitFeedback`), числа — в её `WeaponDef`:

* **отдача** — взгляд вверх (`CatacombTestRig.AddKick`) и пружина модели (как у гранатомёта);
* **тряска** камеры (`AddShake`) по силе выстрела и по удалённости взрыва;
* **хитстоп** через `GameClock` (M0.4): 30–90 мс на сильные события — монета, рельса,
  выстрел по ядру, тяжёлый удар молота. Не на каждый гвоздь;
* **вспышка** — пул из трёх точечных источников (`CaveExplosions` уже держит пул: на WebGL2
  потолок 32 видимых источника на камеру — `CLAUDE.md`, «Ограничения пайплайна»);
* **звук слоями**: щелчок-транзиент + тело + хвост с эхом катакомб, высота ±6%, ограничение
  голосов на звук (не больше 6 одновременных гвоздей);
* **маркер попадания** у прицела и отдельный звук убийства; крит — крупнее и выше тоном;
* **модель живёт**: отдача, перезарядка, нагрев (модель краснеет через `MaterialPropertyBlock`,
  не `renderer.material`, грабли №3).

## M2.5 Пушки подробно

Все числа — **стартовые**, урон в HP (M0.2: мелочь 10, тарантул 40). Уровни 2–5 — по одной
строке; конкретные дельты в `WeaponDef`.

### 1. «Барабан» — многозарядный гранатомёт (переезд)

* **Роль**: отход по коридору, площадь. Уже есть и проверен.
* **Огонь**: как сейчас — 6 гранат, 0.32 с, перезарядка 2.1, радиус 5, урон 30, взрыватель
  по близости, дуга под перекрестие.
* **Альт «Липучка»** (ур. 3): граната прилипает к камню и ждёт; второе нажатие альта
  взрывает все (до 3). Ловушка на отходе: заминировал развилку — отошёл — подорвал под толпой.
* **Уровни**: +1 граната; +15% радиуса; +20% урона; −20% перезарядки; +1 липучка.
* **Ощущение**: глухой «тумп», проворот барабана (уже есть), тяжёлая тряска.

### 2. «Монета» — револьвер (Marksman из Ultrakill)

* **Роль**: снайпер по одиночкам — элита, особые пауки (M3), Матка. Единственная пушка,
  вознаграждающая точность.
* **Огонь**: мгновенный луч (`HitRay`), урон 45, пробивает 3 (−25% на каждого следующего),
  2.5 выстрела/с, 6 в барабане, перезарядка 1.2 с. По элите, особым и Матке — всегда крит ×2
  («глаза» — у них слабое место условное, без попадания в точку: иначе на мобильных пушка мертва).
* **Альт «Монетка»** (ур. 3): подбросить монету (4 заряда, 1 за 2.5 с). Выстрел в монету
  (сфера 0.6, при помощи прицеливания ×2) — **рикошет** в самую опасную цель в 30 юнитах
  на прямой видимости (Матка > особый > элита > самый крупный) с уроном ×2.5. Несколько
  монет в воздухе — пуля прыгает с монеты на монету, ×1.5 за каждую. Хитстоп 60 мс и звон.
* **Тач**: альт подбрасывает и сам стреляет в монету через 0.35 с — фантазия остаётся,
  точность не требуется.
* **Уровни**: +20% урона; +1 пробитие; +1 монета; −20% перезарядки; +10% шанс крита по всем.
* **Ощущение**: сухой резкий выстрел, вспышка, взвод курка на модели.

### 3. «Ядро» — дробовик (Shotgun из Ultrakill, Doom)

* **Роль**: «отстань» вплотную. Отброс — главное, урон второе.
* **Огонь**: `HitCone` 9° дальностью 12, полный урон до 4 юнитов, дальше спад к 20%;
  80 урона в упор; отброс 9 и оглушение 0.4 с. 1.1 выстрела/с, 8 патронов, заряжание
  по одному (0.45 с), прерывается выстрелом. Убийства в упор дают ×2 временного здоровья.
* **Альт «Выброс ядра»** (ур. 3, откат 4 с): ядро летит дугой и взрывается при ударе
  (радиус 4, урон 50). **Выстрел в ядро в полёте** — детонация ×2 радиуса и ×1.5 урона,
  хитстоп. Это главный «стильный» приём пушки.
* **Уровни**: +2 дробины (шире урон по конусу); +30% отброса; −20% заряжания; +25% радиуса
  ядра; +20% урона.
* **Ощущение**: тяжёлая отдача 5°, помпа на модели, «бум» с хрустом.

### 4. «Гвоздомёт» (Nailgun из Ultrakill)

* **Роль**: контроль. Замедляет толпу, держит коридор.
* **Огонь**: 14 гвоздей/с снарядами (`ProjectileSystem`, скорость 60, лёгкий разброс),
  урон 6, каждый гвоздь замедляет на 6% (суммируется до −45%, держится 1.5 с — «гвозди
  в лапах»). Нагрев: +5 за гвоздь из 100, остывание 35/с, перегрев — 1.5 с блокировки.
* **Альт «Магнит»** (ур. 3): бросок магнита, прилипает к камню или пауку, живёт 6 с, до 2.
  Гвозди, пролетающие в 8 юнитах, заворачивают на орбиту вокруг него (радиус 2.5) и бьют всё,
  что пробегает. Мясорубка в развилке.
* **Уровни**: +20% темпа; +20% урона; +замедление; +3 с магниту; −25% нагрева.
* **Ощущение**: стрекот, мелкая частая отдача, ствол краснеет при нагреве.
* Снарядов живых — до ~30 (14/с × 0.5 с полёта + орбита). Отрисовка — один динамический меш
  росчерков, как брызги.

### 5. «Прострел» — рельсотрон (Railcannon из Ultrakill)

* **Роль**: прочистить галерею. Пушка, ради которой в планировке есть `GalleryShare` —
  медиана линии 14–16 юнитов и 36–39% точек с линией 20+ (`CLAUDE.md`, «Замеры»).
* **Огонь**: удержание — заряд 0.9 с (можно держать заряженной), отпустил — луч `HitRay`
  на 120 юнитов до камня, ширина 0.8, пробивает всех, урон 220, отброс вдоль луча.
  Откат 6 с. По камню в конце — гарь (`CaveBlastMarks`, без воронки).
* **Альт «Отвёртка»** (ур. 3): болт втыкается в первую цель и сверлит 4 с по 60 урона в секунду,
  игнорируя щит-множители Матки, общий откат. Против элиты и Матки.
* **Уровни**: −15% отката; +25% урона; +50% ширины; −30% времени заряда; перезаряд
  (держать 2 с — урон ×1.5).
* **Ощущение**: нарастающий вой заряда, **стоп-кадр 80 мс**, белый луч гаснет 0.4 с,
  удар FOV, сильная тряска. Самая «громкая» пушка.

### 6. «Напалм» — огнемёт

* **Роль**: отказ в территории. Отходишь — за тобой горит пол, толпа бежит через огонь.
* **Огонь**: конус 22° на 7 юнитов, 10 ударов/с по 9 урона + горение 3 с по 12/с.
  Горение перекидывается на соседей в 1.5 юнита (25% в секунду) — горящие бегут дальше
  в толпу и разносят огонь. Топливо 100, −20/с, восполнение 15/с без стрельбы.
* **Огонь на полу**: раз в 0.25 с стрельбы — пятно на ближайшем камне по прицелу (радиус 1.6,
  живёт 5 с, поджигает пересекающих, до 24 пятен). Пятно оставляет гарь — `CaveBlastMarks`
  уже умеет копоть и тлеющий жар шейдером, отдельной системы не нужно.
* **Альт «Выдох»** (ур. 3, 40 топлива, откат 6 с): кольцо огня вокруг игрока радиусом 4.5,
  отброс 12 и поджог. Кнопка «меня окружили».
* **Уровни**: +1.5 дальности; +30% горения; +25% ширины конуса; +40% топлива; +2 с пятнам.
* **Ощущение**: ревущий цикл звука, мерцающий свет (один источник из пула), чернеющие трупы.
* **Риск цены**: 10 конусов в секунду + распространение. Замерить на 1200 особях; если дорого —
  конус раз в 0.15 с с пропорционально большим уроном.

### 7. «Дуга» — тесла-ружьё

* **Роль**: снимать пауков со стен и свода (на своде у игрока 40–60% толпы — `CLAUDE.md`),
  куда гранатой не попасть. **Лучшая пушка для тача**: наводится сама.
* **Огонь**: удержание — захват ближайшего в конусе 12° на 14 юнитах (`FindNearest`),
  молния прыгает ещё на 4 цели в 5 юнитах (−15% за прыжок), 8 ударов/с по 16 урона,
  ток 0.25 с — оглушение. Батарея 100, −18/с, заряд 25/с.
* **Альт «Громоотвод»** (ур. 3): воткнуть катушку (до 2), 8 с бьёт трёх ближайших в 7 юнитах
  раз в 0.5 с. Перекликается с пилонами Матки — та же эстетика.
* **Уровни**: +1 прыжок; +20% урона; +3 юнита захвата; +30% батареи; +4 с катушке.
* **Ощущение**: треск, синие вспышки, молния — ломаная линия, перестраиваемая каждый кадр
  (один динамический меш на все дуги).

### 8. «Забой» — кирка-молот (ближний бой Vermintide 2)

* **Роль**: ближний бой с рассечением и **возвращение кирки** — копание, заявленная механика
  проекта, сейчас выключенная (`diggingEnabled`), становится частью пушки.
* **Огонь**: серия из трёх взмахов (0.38 с каждый), дуга 110°, досягаемость 3, урон 40/30/55,
  рассечение до 6 целей (каждая следующая −15%), оглушение 0.3 с, отброс 5. Убийство —
  1.5 временного здоровья. Хитстоп 40 мс при попадании по трём и больше.
* **Удержание — удар оземь** (0.6 с замах): ударная волна радиусом 4.5, 90 в центре,
  отброс 14 — и **воронка в полу** тем же трактом, что у гранаты (`CaveBlastMarks.Blast`
  → `CatacombWorld.Dig` + переразметка сетки пауков).
* **Альт «Пробой»** (ур. 3, откат 8 с): рывок-удар на 4 юнита, **прокапывающий тонкую стену**
  до 3 юнитов породы (цепочка сфер `Dig` радиусом 1.6) — свой короткий ход из окружения.
  Первые 0.2 с альта — **парирование** (Feedbacker из Ultrakill): плевок Матки или особого
  паука, попавший в это окно, летит обратно с ×3 уроном, +10 здоровья.
* **Уровни**: +20% урона; +2 цели рассечения; +1 радиуса удара оземь; −2 с отката пробоя;
  ×1.5 временного здоровья.
* **Ощущение**: замах с размытым следом, глухой хруст, пыль от камня, вес — пушка медленнее
  всех остальных, и это правильно.
* **Ограничения копания**: не чаще одного пробоя в 8 с и удара оземь в 1.2 с (бюджет копания
  и перестройки — `CLAUDE.md`, «Воронка»: до 4 мс на яму). Граница мира защищена
  `BoundaryThickness`. Копание только **добавляет** связность — гарантия «тупиков 0» не ломается.
  Открытый вопрос из `CLAUDE.md` «реквизит висит над ямой» обостряется — пилоны и логово
  копанию не подлежат (сфера-запрет вокруг них).

## M2.6 Звук

Звука оружия в проекте нет; синтезирован только шорох толпы. Для пушек синтез не годится —
нужен пак (пользователю: GDC-бандлы Sonniss — роялти-фри; CC0 с freesound; или покупной
пак «sci-fi/industrial weapons»). Пока пака нет — заглушки, синтезированные кодом (щелчок,
шум с огибающей), чтобы тракт и ограничение голосов были готовы.

* Пул из 16 `AudioSource`, приоритеты: игрок > Матка > особые > толпа.
* Клипы короткие, Vorbis, «Decompress On Load» только для частых (гвозди, молния).
* Эхо катакомб — `AudioReverbZone` или фильтр на шине; **проверить на WebGL** — часть фильтров
  Unity там не работает, тогда эхо запекается в хвост клипа.

## M2.7 «Стиль» (необязательно)

Счётчик стиля Ultrakill, упрощённый: убийства тремя разными пушками в пределах 6 с дают
«КОМБО» — ×1.25 опыта на 10 с. Учит переключаться, без отдельного интерфейса — значок у
полосы опыта. Делать после того, как восемь пушек сбалансированы.

## M2.8 Приспособления (необязательно, после релиза)

Автономные предметы VS/Megabonk — отдельный тип карточки, 2 слота: «Светлячок» (дрон,
стреляет в ближайшего), «Кольцо пил» (орбита вокруг игрока), «Прыгуньи» (мины),
«Фальшфейер» (свет, отпугивающий толпу, — `CaveFlare` уже есть, нужна механика паники).
Они дают VS-ощущение «экран сам чистится», которое ручная стрельба не даёт.

## Критерии готовности M2

| проверка | ожидание |
|---|---|
| `WeaponCheck` (новый прогон) | для каждой пушки на синтетической раскладке в прямом ходе: форма поражения верна (конус не бьёт за углом, луч пробивает ровно N, цепь не длиннее K, дуга молота в своём секторе); **ни одного попадания сквозь стенку** (раскладка в соседнем ходе за перегородкой 1 юнит); убийства приписаны своему источнику; цена одного выстрела в мс |
| таблица DPS | прогон печатает урон в секунду по толпе и по одиночке для каждой пушки на уровнях 1 и 5 — вход для баланса M6 |
| `CatacombRunCheck` | проходит с каждой из восьми пушек у бота (бот выбирает пушку по номеру) |
| `CatacombCrowdCheck` | «Поражение», «Воронка» — без изменений (гранатомёт переехал без изменений) |
| кадры | для каждой пушки: выстрел в пустом ходе и в группе при остановленном времени (грабли №63) |
| `CLAUDE.md` | раздел на каждую пушку: роль, числа, что пробовали и почему отказались |
