# M6 — Баланс, аналитика, удержание

Цель: достойные удержание и время игры на веб-площадках. Это не одна задача, а режим работы
после M1–M5: симуляция даёт стартовые числа, аналитика — настоящие, функции удержания
дают причину вернуться.

---

## M6.1 Симуляция баланса (`ProgressionSim`)

Людей в прогоне нет, но **ботов с ограниченным уроном** проект уже умеет (`CatacombRunCheck`:
«игрок» с взрывом радиуса 5 раз в 0.75 с — грабли №45: бесконечный урон меряет не то).
Расширить до бота с ростом:

* бот подбирает ихор (стоит на месте или пятится по полю потока — «отход по коридору»),
  на уровне выбирает карточку по **сценарию билда** (например: «Барабан до 5 → Охват → Ядро»),
  стреляет пушкой из M2 через её же логику (не формулой), рывком уходит при потолке урона;
* три профиля: **новичок** (точность 40%, рывок поздно, без мета), **средний** (70%,
  мета на ~30%), **сильный** (90%, мета полная, оптимальный билд);
* прогон на 5 сидах × 3 профиля × ярусы 1–3 печатает: время смерти, уровень по минутам,
  пушки и тома, урон по источникам, срабатывания милосердия, хитин за забег.

**Целевые окна** (стартовые; уточняются аналитикой):

| | новичок | средний | сильный |
|---|---|---|---|
| смерть на ярусе 1, глубина 1 | 3:00–4:30 | доходит до Ткачихи | проходит |
| ярус 3, глубина 1 | — | 50% доходит | проходит за 18–22 мин |
| глубина 3 | — | — | 50% проходит |
| уровень к концу яруса 1 | 7–9 | 9–12 | 11–13 |
| хитин за забег | 60–120 | 150–300 | 400+ |

**DPS-таблица** из `WeaponCheck` (M2) на уровнях 1/3/5/эволюция против толпы и одиночки:
ни одна пушка не должна быть лучшей по обоим столбцам — иначе разнообразие умирает
(у VS это лечили годами).

## M6.2 Аналитика

Без неё баланс — догадки. Событийный слой `IAnalytics` (заглушка в редакторе, отправка
по выбору пользователя — `README.md`, вопросы):

| событие | поля |
|---|---|
| `boot` | время загрузки до `GameReady`, платформа, качество, язык |
| `first_input` | секунд от `GameReady` |
| `run_start` | класс, глубина, пушка, номер забега профиля |
| `stage_clear` / `death` | ярус, время, уровень, причина (вид, особый, Матка, финальный рой), пушки, тома |
| `level_up` | предложенные и выбранная карточки |
| `purchase` | улучшение / пушка, цена, хитин после |
| `ad` | место, тип, результат (показана / ошибка / закрыта до конца) |
| `quest_done`, `unlock` | что |
| `session_end` | длительность, забегов |

Воронка первой сессии: `boot → first_input → run_start(1) → death(1) → run_start(2) →
purchase(1) → run_start(3)`. Главная метрика первой недели — **доля дошедших до второго
забега**: если меньше 70%, проблема в первых минутах, а не в мете.

## M6.3 Удержание

| приём | откуда | вехa |
|---|---|---|
| открытие каждые 1–2 забега первые 2 часа | VS | M4.4 экономика |
| «до следующего открытия — N» на итогах | Megabonk | M1.5 |
| ежедневные задания (3) | мобильные F2P | M4.6 |
| серия входов (7 дней) | мобильные F2P | M4.6 |
| ящик дня за рекламу | веб-площадки | M5.3 |
| лидерборд по глубине «Бездна» | Megabonk (тиры), VS | M4.8 + M5.2 |
| **еженедельный мутатор** («Неделя тьмы»: лампы ×0.3, хитин ×1.5) | Vermintide 2 (еженедельные события) | новое, после выпуска |
| косметика пушек за задания | все трое | M4.6 |
| новые пушки/Матки обновлениями | — | у площадок обновление поднимает в выдаче |

**Чего не делать**: принудительного таймера энергии, рекламы посреди забега, платного
ускорения меты на старте — рейтинг Яндекса ниже 30 снимает игру с публикации (M5.1).

## M6.4 KPI, на которые ориентироваться

Конкретные цели согласовать с пользователем; разумная отправная точка для жанра на вебе:

| | цель |
|---|---|
| загрузка до игры (медиана) | ≤ 12 с ПК, ≤ 20 с телефон |
| дошли до 2-го забега | ≥ 70% |
| среднее время сессии | ≥ 15 мин |
| D1 | ≥ 25% |
| D7 | ≥ 8% |
| рейтинг на Яндексе | ≥ 4.0 (снятие при ≤ 30 из 100 в их шкале) |

## M6.5 Ритм обновлений после выпуска

1. Неделя 1–2: правки баланса по аналитике (только числа в ассетах — без пересборки логики).
2. Приспособления (M2.8) — VS-ощущение «экран чистится сам».
3. Мини-боссы ярусов (M3.6), еженедельный мутатор.
4. Новый класс + пушка раз в 3–4 недели.
