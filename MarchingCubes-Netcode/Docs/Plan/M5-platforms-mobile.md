# M5 — Площадки и мобильные: Yandex Games, CrazyGames, тач

Цель: сборка WebGL, которую примут обе площадки, которая грузится быстро, держит кадр
на телефоне среднего класса и управляется пальцами.

Оценка: 4–5 сессий. Зависит от M1 (интерфейс), M4 (профиль). Тач-управление можно
начать сразу после M0.6.

---

## M5.1 Требования площадок (сверено с документацией, октябрь 2026)

Перед выпуском — перечитать первоисточники, требования меняются:
`docs.crazygames.com/requirements/` и `yandex.ru/dev/games/doc/ru/concepts/requirements`.

**CrazyGames**

| | |
|---|---|
| начальная загрузка | **≤ 50 МБ**; для мобильной главной — **≤ 20 МБ** (меряется до первого `gameplayStart`) |
| всего | ≤ 250 МБ, ≤ 1500 файлов |
| до игры | ≤ 20 с; новый игрок — сразу в игре или за 1 клик |
| устройства | Chrome, Edge; Chromebook с 4 ГБ памяти; Unity на iOS выключен по умолчанию (память) |
| ввод | мышь, клавиатура и тач, если заявлен мобильный |
| язык | английский обязателен, язык — из системной информации SDK, запасной английский |
| экран | своя кнопка полноэкранного режима **запрещена**; размеры от 800×450 |
| реклама | только через SDK; midgame — между уровнями/при смерти, не на кнопках навигации; игра на паузе и без звука; `adError` — продолжить игру; без цепочек реклам |
| прочее | частота кадров не влияет на физику (144/165 Гц) |

**Yandex Games**

| | |
|---|---|
| SDK | инициализация строго по документации; `LoadingAPI.ready()` в момент, когда можно играть; `GameplayAPI.start/stop` — по разметке геймплея |
| размер | **≤ 100 МБ** всех файлов в распакованном виде; `index.html` в корне; без пробелов и кириллицы в именах файлов сборки |
| звук | при потере фокуса — остановить |
| прогресс | сохраняется сразу после действия; не теряется при обновлении страницы и повороте экрана |

| язык | автоопределение через SDK |
| реклама | только через SDK, в логических паузах; за вознаграждение — по кнопке |
| экран | на мобильных — полноэкранный режим; элементы не обрезаются при смене размера и повороте; без прокрутки страницы и swipe-to-refresh |
| содержание | от 10 минут игры или мотивация перепроходить; нарастающая сложность; управление описано |
| рейтинг | ниже 30 три недели — снимают с публикации |

## M5.2 Слой платформы

```
IPlatformServices
  Init() / GameReady()           — Yandex LoadingAPI.ready, CrazyGames loadingStop
  GameplayStart() / Stop()       — по GameFlow: Playing ⇄ всё остальное
  ShowInterstitial(cb) / ShowRewarded(cb)
  CloudLoad/CloudSave            — бэкенд SaveService (M4.2)
  Language, DeviceType           — из SDK
  SubmitScore(board, value)
  Happytime()                    — CrazyGames, после победы над Маткой
  событие Paused/Resumed         — пауза от площадки (реклама, вкладка)
```

* Реализации: `EditorPlatform` (заглушка: реклама — диалог «досмотрел/закрыл», сохранение
  в файл), `YandexPlatform` (тонкий `.jslib` к SDK v2 — вызовы `ysdk.*` и колбэки через
  `SendMessage`), `CrazyGamesPlatform` (официальный Unity SDK v3 от CrazyGames).
* **Профили сборки Unity 6** (Build Profiles) на каждую площадку со своими define:
  `PLATFORM_YANDEX`, `PLATFORM_CRAZYGAMES`; шаблон WebGL — свой на площадку.
* **Шаблон WebGL**: полоса загрузки в стиле игры, подключение SDK (у Яндекса — `/sdk.js`),
  CSS `user-select: none; touch-action: none; overscroll-behavior: none`, запрет контекстного
  меню, обработка `visibilitychange` → `GameClock.FocusLost` (M0.4).
* **`GameplayStart/Stop` строго по `GameFlow`**: `Playing` — старт; пауза, карточки уровня,
  привал, итоги, лагерь — стоп. Карточка уровня — стоп, потому что время стоит.

## M5.3 Реклама

| место | тип | условие |
|---|---|---|
| переход «Итоги → новый забег» | межстраничная | не раньше 3-го забега, не чаще раза в 3 мин; **не** на кнопке «В лагерь» (навигация) |
| переход между ярусами | межстраничная | не чаще раза в 3 мин; на экране загрузки, пока генерируется уровень |
| смерть | за вознаграждение | «Возродиться» — раз за забег |
| итоги | за вознаграждение | «Хитин ×2» |
| карточки уровня | за вознаграждение | «Переброс», раз за уровень |
| привал | за вознаграждение | «Полное лечение» |
| лагерь | за вознаграждение | «Ящик дня» (хитин), раз в день |

На время любой рекламы: `GameClock.Ad` (время и звук стоят), ввод заблокирован, ошибка
или незаполненный показ → игра продолжается, награда за вознаграждение не выдаётся
(и кнопка не врёт — CrazyGames отклоняет игры с кнопками рекламы «без эффекта»).
Счётчики частоты — в профиле (M4.2).

## M5.4 Локализация

* Таблица `Resources/Localization/strings.csv` (ключ; ru; en; tr) → словарь при старте,
  `Loc.T(key)`. Ключи завела M1.9. Пакет `com.unity.localization` не брать: тяжёлый
  для 3 языков и сотен строк.
* Язык: SDK площадки → профиль (если игрок выбрал сам) → английский.
* **Шрифт**: один OFL-шрифт с кириллицей и турецкими (ğ ş ı İ ç ö ü), статический TMP-атлас
  только с нужными символами (собирается из таблицы строк) — динамический атлас тянет
  весь шрифт в сборку.
* Числа и время — без культуры системы (`CultureInfo.InvariantCulture`), иначе в турецкой
  локали ломается разбор строк (`ToUpper` для «i»).

## M5.5 Тач-управление

| зона | что |
|---|---|
| левая половина | плавающий джойстик — появляется под пальцем |
| правая половина | перетаскивание — взгляд (своя чувствительность и кривая ускорения) |
| кнопки справа | **огонь** (удержание), **альт**, **рывок**, **смена пушки** (касание — следующая, удержание — круговое меню из 3) |
| кнопка слева сверху | пауза |
| контекстная | «Разбудить» / «Спуститься» у логова и провала |

* **Автоогонь** (по умолчанию на таче): пушка стреляет сама, пока перекрестие на цели.
  Для гранатомёта и рельсы — нет (они на кнопке): автоогонь гранатой себе под ноги — смерть.
* **Помощь прицеливания**: магнетизм — взгляд мягко подтягивается к ближайшей цели
  в конусе 6° (`FindNearest`, M2.2), «липкость» — чувствительность ×0.6 над целью;
  попадание луча с увеличенным радиусом ×1.5. Для мыши — выключено.
* Мультитач через `Input.touches` (старый Input Manager работает в мобильных браузерах),
  каждое касание закрепляется за зоной при начале и не перескакивает.
* Кнопки — по `Screen.safeArea`, размер ≥ 9 мм (в dpi устройства), раскладка настраивается
  (перетаскиванием в настройках — после выпуска).
* Только горизонтальная ориентация (площадки умеют её фиксировать — CrazyGames сама просит
  повернуть устройство).

## M5.6 Качество графики

Три уровня, автоопределение + замер. Автоопределение: тип устройства из SDK, `SystemInfo`
(память, видеокарта); замер — средний кадр первых 10 с забега, при > 26 мс — ступень вниз
(один раз, с сохранением в профиль).

| | Высокое (ПК) | Среднее | Низкое (телефон) |
|---|---|---|---|
| масштаб рендера | 1.0 | 0.85 | 0.65–0.75 |
| потолок толпы (`capacity`) | 1200 | 900 | 600 |
| население | ×1 | ×0.85 | ×0.6 |
| лампы с тенями | нет (уже) | нет | нет |
| пылинки, ореолы | да | да | пылинки нет |
| частицы взрыва | ×1 | ×0.75 | ×0.5 |
| гарь (слотов шейдера) | 16 | 16 | 8 |
| дальность отрисовки толпы | 60 | 50 | 40 |

**Население на Низком меньше — значит и убийств меньше**, а опыт и хитин идут с убийств.
Компенсировать: ценность ихора и шанс хитина ×(1 / множитель населения), живучесть
особей не трогать. Иначе телефонный игрок растёт медленнее компьютерного.

## M5.7 Размер и загрузка

Цель: **начальная загрузка ≤ 20 МБ** (мобильная главная CrazyGames), жёстко ≤ 50 МБ;
всё вместе ≤ 100 МБ (Яндекс).

1. **Отчёт сборки** (`BuildReport`, раздел ассетов по размеру) — прогон `WebGLBuildCheck`
   (см. `verification.md`) пишет топ-30 ассетов и итог сжатых файлов. Без замера не резать.
2. **Модули движка**: убрать из `Packages/manifest.json` неиспользуемые `com.unity.modules.*`
   (terrain, terrainphysics, cloth, vehicles, wind, vr, xr, umbra, video, tilemap,
   physics2d, …) и пакеты, не нужные игре (`visualscripting`, `collab-proxy`, `timeline`,
   если не используется). Каждое удаление — пересборка и прогоны.
3. **Код**: IL2CPP с оптимизацией по размеру, Managed Stripping High (проверить, что
   `JsonUtility`-классы профиля не вырезаются — `[Preserve]` / `link.xml`).
4. **Карты анимации пауков** (~7 МБ, крупнейшее): квантование позиций в 16 бит
   на канал относительно габаритов клипа вместо `RGBAHalf` — открытый вопрос из `CLAUDE.md`
   («резать надо точность карт, а не число видов»). Проверка — кадром и прогоном толпы.
5. **Текстуры** породы и паков: сжатие под WebGL (DXT/BC для ПК, ASTC/ETC2 для мобильных),
   размеры не больше нужного в кадре.
6. **Звук**: Vorbis, моно для эффектов, музыка — потоком.
7. **Сжатие сборки** — Brotli или Gzip по требованиям хостинга площадки (у CrazyGames
   есть страница «Unity custom build» — свериться перед выпуском).
8. **Первый показ шейдеров**: `ShaderVariantCollection` с прогревом на экране загрузки,
   отсев лишних вариантов URP. Замер подвисания первого взрыва/первой пушки в сборке.

## M5.8 Бюджет кадра на WebGL

Мерить **только сборкой** (в редакторе Burst-джобы и лимиты света другие — `CLAUDE.md`).

| система | ПК | телефон |
|---|---|---|
| толпа (поведение + отрисовка) | ≤ 4 мс | ≤ 6 мс |
| ихор, снаряды, статусы | ≤ 1 мс | ≤ 1.5 мс |
| копание и перестройка чанков | ≤ 8 мс на кадр с ямой (уже бюджет) | то же, реже |
| интерфейс | ≤ 0.5 мс, 0 аллокаций | то же |
| итого | 60 к/с | 30+ к/с |

Проверить отдельно (открытые вопросы `CLAUDE.md`): потолок **32 видимых источника света**
на камеру в длинной галерее и стоимость запекания `MeshCollider` при воронках.

## M5.9 Нативный Android (после выпуска на вебе, по решению пользователя)

Код к этому готов, если M0–M5 сделаны по плану: ввод — слой, качество — уровни, сохранения —
бэкенд. Новое: `AndroidPlatform` (реклама — отдельная сеть, сохранения — Play Games),
многопоточность Burst (на Android воркеры есть — толпу можно поднять до 1500).

## Критерии готовности M5

| проверка | ожидание |
|---|---|
| `WebGLBuildCheck` | сборка проходит для обоих профилей; начальная загрузка ≤ 20 МБ (цель) / ≤ 50 МБ (порог); всё ≤ 100 МБ; ≤ 1500 файлов; имена файлов без пробелов и кириллицы |
| заглушка платформы | реклама/ошибка рекламы/отмена — игра продолжается во всех местах M5.3 |
| ручной проход в браузере | загрузка ≤ 20 с; фокус ушёл — звук и время стоят; обновление страницы — профиль и контрольная точка на месте |
| телефон (Chrome Android, средний) | 30+ к/с на ярусе 1 на «Низком»; тач: движение, взгляд, огонь, рывок, смена пушки — одновременно двумя пальцами |
| песочницы площадок | Yandex — черновик проходит автопроверки; CrazyGames — QA-инструмент SDK без ошибок |
| `CLAUDE.md` | разделы «Площадки», «Тач», «Качество», «Размер сборки» с замерами |
